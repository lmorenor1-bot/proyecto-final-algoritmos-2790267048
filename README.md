# Sistema de Caja para una Tienda

## Descripción del proyecto

Este proyecto consiste en un sistema de caja desarrollado en C++ para una tienda. Permite registrar productos, calcular subtotales, aplicar descuentos, calcular el IVA, recibir pagos y determinar el cambio correspondiente.

También permite consultar un resumen de las ventas realizadas durante la ejecución del programa.

## Lenguaje y herramientas utilizadas

- C++
- Visual Studio Code
- Compilador G++ (MSYS2)
- Git y GitHub

## Funcionalidades

- Menú principal con tres opciones.
- Registro de varios productos por venta.
- Validación de precios, cantidades y opciones.
- Descuentos del 0 %, 5 % y 10 %.
- Cálculo del IVA del 12 %.
- Validación del pago recibido.
- Cálculo del cambio.
- Generación de recibos.
- Resumen de ventas del día.
- Cierre de caja.

## Compilación y ejecución

Para compilar el programa:

```text
g++ main.cpp -o caja.exe
```

Para ejecutarlo en PowerShell:

```text
.\caja.exe
```
